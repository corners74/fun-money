# Fun Money 🎉

A tiny app that shows one number: what you can spend freely this week.

## Where your numbers live
- Only inside the app on your device. Nothing is sent anywhere.
- This code contains **no personal numbers** — a fresh copy starts with example figures.
- Tap **💾 Save a backup** now and then. Backups (`.json`) and bank files (`.csv`) are blocked from GitHub by `.gitignore`.

## On iPhone
Open the web address in Safari → Share → **Add to Home Screen**.
